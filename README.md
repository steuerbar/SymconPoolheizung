# Poolheizung für Symcon

Store-taugliche Visualisierungskachel für einen hydraulisch getrennten Pool-Heizkreis mit Solarabsorber, Plattenwärmetauscher und Poolkreis.

- animierte Primär- und Sekundärkreise
- vier temperaturabhängig eingefärbte Messwerte
- Pumpenstatus Q1/Q2
- sichere Start-/Stoppimpulse über SPS-Merker M4/M5
- keine doppelten Messvariablen
- konfigurierbare Zuordnung vorhandener Symcon-Variablen

Empfohlene Kachelgröße: mindestens 3 × 3 Felder.
